# Administrator Guide

This guide describes platform administration, course creation, user management, audit logging, and analytics for administrators of **EnglishBuddy**.

---

## 1. Accessing the Admin Console

Navigate to `/admin` using an account with `ADMIN` or `SUPER_ADMIN` privileges.

---

## 2. Content & Course Management

- **Creating Courses**: Navigate to `/admin/courses` to create new learning paths, modules, and lessons.
- **Publishing Lessons**: Manage lesson status (`DRAFT` vs `PUBLISHED`) and set XP reward values.
- **Uploading Media Resources**: Upload worksheets, reading PDFs, and lesson images via `/admin/resources` with automatic media optimization.

---

## 3. User & Security Oversight

- **User Management (`/admin/users`)**: Search learners, update roles (`Student`, `Premium Student`, `Instructor`, `Moderator`, `Admin`), and reset user lockouts.
- **Audit Logs (`/admin/audit-logs`)**: Inspect security events, failed login spikes, password resets, and subscription changes.
- **System Metrics (`/admin/analytics`)**: View real-time platform metrics, active streak counts, and AI quota utilization.
